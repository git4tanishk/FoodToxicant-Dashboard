# FoodToxicant-Dashboard
Food toxicants research dashboard — 17K+ PubMed papers, live multi-filter, Chart.js visualizations. Pure HTML/CSS/JS, no framework.
A fully client-side research literature dashboard indexing 17,170+ 
original research papers on food toxicants, contaminants, and food safety 
from PubMed (2000–2026).

Built with pure HTML, CSS, and JavaScript — no framework, no backend.
Processes 170,000+ records from CSV datasets compressed into index arrays.

Features: 9-category filter system, 7 multi-select filter dimensions, 
dual-range year slider, full-text search, Chart.js visualizations, 
paginated results table, CSV export, and paper detail modals linking to PubMed.
